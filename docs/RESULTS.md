# Отчёт: OpenVLA baseline и первый CS-8 пилот

Дата среза экспериментов: **10 ноября 2026 года**. Это офлайн-оценка действий
на наблюдениях из демонстраций Jaco Play. Робот или симулятор не исполнял
выбранные действия.

## Вывод для команды

Baseline близко воспроизведён на Jaco Play. В первом переносе CS на одношаговую
OpenVLA выигрыша относительно обычного greedy нет: AMSE выше на **2,26%**.
Мы получили проверенный отрицательный результат конкретного пилота, пригодный
для дальнейшей диагностики, а не доказательство бесполезности CS вообще.

Разложение ошибки указывает на захват как источник ухудшения общей метрики.
Это мотивирует отдельный эксперимент, но не доказывает, что изменение обработки
захвата повысит успешность управления.

## 1. Что именно проверяли

Исходная идея CS: сгенерировать несколько действий/чанков и выбрать существующего
кандидата с наибольшей суммарной Gaussian similarity к остальным. Переносим
правило выбора с action-chunking политик OAT на семейство OpenVLA.

В этом пилоте обычная OpenVLA выдаёт **одно 7D-действие на наблюдение**.
Поэтому `H=R=1`: восемь вызовов дают восемь альтернатив одному шагу, а не
траектории на восемь будущих шагов. Это проверка одношагового случая CS.

| Параметр | Зафиксированное значение |
| --- | --- |
| Model | `openvla/openvla-7b` |
| Model revision | `47a0ec7fc4ec123775a391911046cf33cf9ed83f` |
| MultiNet commit | `546a1c77f9a4cc0544c5e4b41565949778d32441` |
| Dataset | `jaco_play/0.1.0`, официальный `test` |
| Full baseline | 109 эпизодов, 7838 шагов |
| CS pilot | Первые 20 эпизодов в том же TFDS/loader порядке, 1487 шагов |
| Sampling | `N=8`, temperature `1.0`, top-k `10`, top-p `1.0`, seed `7` |
| Hardware | 2 × Tesla T4, FP16, eager attention, без квантования |
| Preprocessing | Авторские prompt, center crop area 0.9 и action adapters |
| Normalization | Замороженные q01/q99 и mask из закреплённого MultiNet |

`manifest.generation_config` содержит базовые defaults модели, включая
`do_sample=false` и `top_k=50`. Реальные параметры stochastic вызовов
переопределяются при генерации; они записаны в `protocol` и приведены выше.

Sampling settings выбраны заранее для exploratory pilot; validation tuning
не проводился. Первые 20 test-эпизодов не являются случайной выборкой split.

## 3. CS: сравнение только на общих 20 эпизодах

Greedy вычислен отдельно на тех же входах. Single sample, Random-8, Medoid-8
и CS-8 используют **один и тот же pool из восьми кандидатов** в каждом кадре.
Single sample — первый кандидат; Random-8 выбирает равномерный случайный индекс
с отдельным RNG. Greedy не входит в кандидатный pool.

| Метод | AMSE ↓ | NAMSE ↓ | Δ AMSE к greedy | Относительное изменение |
| --- | ---: | ---: | ---: | ---: |
| Greedy | 0.2315849059 | 0.2270614506 | 0 | 0% |
| Single sample | 0.2376199629 | 0.2322724281 | +0.0060350570 | +2,61% |
| Random-8 | 0.2363625107 | 0.2247454599 | +0.0047776048 | +2,06% |
| Medoid-8 | 0.2354849168 | 0.2308852841 | +0.0039000109 | +1,68% |
| CS-8 | 0.2368161663 | 0.2321905308 | +0.0052312604 | **+2,26%** |

**Нельзя подставлять в эту таблицу baseline AMSE=0.2379872 со всех 109 эпизодов:**
так получилось бы ложное впечатление выигрыша CS из-за разных наборов кадров.
Все 1487 greedy-предсказаний пилота точно совпали с соответствующим фрагментом
полного baseline; также совпали image hashes, инструкции, targets и boundaries.

### Неопределённость

Парный bootstrap: 2000 выборок эпизодов с возвращением, по 20 эпизодов в каждой;
AMSE в каждой выборке взвешивается числом шагов. Сравниваем методы на одних и тех
же выбранных эпизодах. RNG seed `200010`; границы — элементы 49 и 1949
отсортированных 2000 разностей, индексация с нуля.

| Разность | Δ AMSE | 95% episode bootstrap interval |
| --- | ---: | --- |
| CS − greedy | +0.0052313 | [+0.0005037; +0.0114388] |
| CS − single sample | −0.0008038 | [−0.0062013; +0.0038895] |
| CS − Random-8 | +0.0004537 | [−0.0034655; +0.0038294] |
| CS − Medoid-8 | +0.0013312 | [−0.0000564; +0.0041245] |

В этом пилоте интервал CS−greedy находится выше нуля: ошибка CS выше.
Остальные три интервала включают ноль; преимущества CS над этими контролями
не установлено. Интервалы условны на конкретных 20 эпизодах и одном sampling seed;
они не учитывают разброс по повторным запускам генерации и выбору задач.

## 4. Что показывает диагностика

После MultiNet conversion действие Jaco имеет порядок `[gripper, x, y, z]`.
Ниже каждый столбец — **вклад в общую AMSE**, то есть соответствующая сумма
средних квадратов ошибок, делённая на 4.

| Метод | Захват: вклад в AMSE | x/y/z вместе: вклад в AMSE | Всего |
| --- | ---: | ---: | ---: |
| Greedy | 0.2273032952 | 0.0042816107 | 0.2315849059 |
| CS-8 | 0.2326832549 | 0.0041329114 | 0.2368161663 |
| CS − greedy | **+0.0053799597** | **−0.0001486993** | **+0.0052312604** |

Суммарная MSE по x/y/z уменьшилась на **3,47%**, однако ухудшение захвата
перевесило. Это разложение уже полученного результата; CS в этом запуске
выбирал по всем непостоянным координатам, а не только по x/y/z.
Смешанная шкала дискретного захвата и непрерывного движения влияет на AMSE;
мы сохраняем авторскую метрику, а не меняем её после получения результата.

| Диагностика | Результат |
| --- | ---: |
| Уникальных нормированных действий в pool | В среднем 2,80 из 8 |
| Все восемь кандидатов одинаковы | 571/1487 кадров, 38,40% |
| CS и medoid выбрали одинаковый индекс | 1285/1487 кадров, 86,42% |
| Невалидных action-токенов | 0 |
| Время генерации pool / время greedy | 7,94× |
| Полное время evaluation пилота | 158,19 минуты |

Все восемь кандидатов генерировались последовательно, без повторного использования
visual encoding. Время pool — 8399,95 с; отдельного greedy — 1058,47 с;
совместного вычисления CS/medoid selection — 0,20 с. Итого оценка включает
и greedy, и pool; 7,94× — отношение времени pool к greedy, а не полное время
всего исследования. Это не equal-compute сравнение.

Малое разнообразие ограничивает возможность выбора. Высокое совпадение с medoid
также означает, что преимущество именно Gaussian scores пока не показано.

## 5. Как считаются метрики и выбор

Для M кадров и 4D Jaco-действий:

```text
mse_t = sum_d (prediction[t,d] - target[t,d])² / 4
AMSE  = mean_t(mse_t)
NAMSE = mean_t((mse_t - min_t mse_t) / (max_t mse_t - min_t mse_t))
```

Min/max в NAMSE вычисляются **отдельно для каждого метода по всем оцениваемым
кадрам**. Поэтому у Random-8 ниже NAMSE при более высокой AMSE: изменился и
диапазон ошибок. NAMSE не является общей нормировкой координат действий.
При нулевом диапазоне evaluator возвращает `null` с `namse_defined=false`.

Выбор выполняется **до** преобразования в Jaco 4D, в нормированном 7D-пространстве.
Для маскированных координат обращается q01/q99 unnormalization; постоянные
rotation dimensions становятся нулями. `mask=False`, включая gripper,
сохраняется без преобразования. Статистики не подгоняются к pool или test.

```text
d_ij = Euclidean distance между нормированными кандидатами
h = median(положительных попарных d_ij) + 1e-6
    либо 1 + 1e-6, если положительных расстояний нет
CS     = argmax_i sum_j exp(-d_ij² / (2h²))
Medoid = argmin_i sum_j d_ij
```

Точные ничьи разрешаются первым индексом. Селектор получает только кандидатов,
не targets. Targets используются evaluator после выбора. Реализация написана
по формулам исследовательской статьи, не перенесена из авторского пакета.

## 6. Проверки результатов

Оба итоговых запуска завершены: baseline v3 и CS pilot v2 имеют статус
Kaggle `COMPLETE`. Частичный CS v1 в итоговые таблицы не включён.

CPU-аудит проверяет coverage и boundaries, исходные токены, нормировку,
CS/medoid scores, Random RNG, Jaco conversion, каждое MSE, итоговые метрики,
bootstrap и соответствие paired greedy полному baseline. SHA-256 фиксирует
включённый архив. Это проверка сохранённых результатов, не повторный inference.

## 7. Что можно и нельзя заключить

- На Jaco подтверждено близкое численное воспроизведение greedy baseline.
- CS при `N=8, R=1, T=1, top-k=10` не улучшил paired greedy в этом пилоте.
- Это один датасет, первые 20 test-эпизодов, один sampling seed и одна настройка.
  Обобщение на все OpenVLA, CS или роботические задачи не обосновано.
- Независимость Jaco test от pretraining OpenVLA здесь не установлена;
  это воспроизведение benchmark protocol, не доказательство generalization.
- LIBERO success rate, multi-step planning и CS над будущими чанками не измерялись.
  Offline final-action exact match из baseline не является success rate.
- Идея «CS только для движения + greedy-захват» появилась после просмотра этих
  test-результатов. Она ещё не проверена. Сначала допустим exploratory replay
  сохранённых кандидатов, затем подтверждение на новых эпизодах с тем же
  разделением для medoid. Нельзя выдавать подбор на этих 20 эпизодах за test gain.
